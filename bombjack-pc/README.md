# 炸弹杰克 · Mighty Bomb Jack 离线单机版

Tehkan 1986 FC 游戏《Mighty Bomb Jack》的完全离线版本。
无需联网、无需安装任何东西，**把整个文件夹复制到其他 Windows 电脑上也能直接玩**。

## 怎么玩

1. **双击 `start.bat`** —— 服务器在后台无窗口运行（cmd 窗口一闪而过自动关闭），
   并自动打开浏览器访问 http://127.0.0.1:9806/
   - 优先使用自带的 `runtime/` 便携 Python（无需安装 Python）；
     没有 runtime 时自动改用系统已装的 pythonw/python
   - 游戏结束时双击 `stop_server.bat` 可停止后台服务器（不停止也不影响游玩）
   - 重复双击 start.bat 不会启动第二个服务器，只会重新打开浏览器
2. 点击画面中央的 **"点击开始游戏"**
3. 开玩！

## 按键

| 按键 | 功能 |
|---|---|
| 方向键 | 移动 / 上下 |
| X | 跳跃（A，空中按住可悬停） |
| Z | B 键 |
| Enter | 开始 / 暂停 |
| Backspace | Select |
| F8 | 快捷截图 |
| F10 | 重置游戏（回到标题画面） |

## 工具栏

- **存档管理**：**6 个存档槽位**，每个槽位都是本地磁盘上的独立文件
  （`saves/slot1.state` ~ `slot6.state`），支持存入 / 覆盖 / 读取 / 删除，
  显示保存时间和大小；刷新页面、重启浏览器、重启电脑都不会丢失
- **按键设置**：8 个动作（上/下/左/右/A 跳跃/B 攻击/Start/Select）均可自定义改键，
  点「改键」后按下新按键即可（Esc 取消），设置自动保存到磁盘 `saves/keys.json`
- **暂停 / 继续**：冻结画面与声音
- **截图**：PNG 自动下载，同时保存一份到 `saves/screenshots/`，快捷键 **F8**
- **音量**：滑条实时调节（0-100%）
- **全屏**：画布保持 4:3 比例最大化居中（Esc 退出）
- **重置**：回到游戏标题画面（等同于主机的 RESET 键），快捷键 **F10**
- **退出**：自动把当前进度存入一个空槽位（没有空槽位时覆盖保存时间最早的槽位），
  然后暂停并显示退出画面；之后可关闭标签页，或点击画面继续游戏
- Esc 键仅用于关闭弹窗 / 取消改键，不会传给模拟器（避免误触内置热键）
- 启动时如果磁盘上有历史存档，会自动提示数量，进游戏后打开「存档管理」选择槽位读取

## 文件说明

```
index.html       游戏页面
nescore.js       模拟核心（WebAssembly 加载器）
nescore.wasm     模拟核心二进制（FCEUmm NES 核心）
game.nes         游戏 ROM
saves/           存档槽位、按键设置与截图（真实磁盘文件）
serve.py         本地静态服务器（纯 Python 标准库，无第三方依赖）
runtime/         内置便携 Python 3.13（约 12MB，免安装，复制即用）
start.bat        一键启动（后台无窗口运行，自动选择 Python）
stop_server.bat  停止后台服务器
```

## 可移植性

- 整个 `bombjack` 文件夹就是一个完整游戏：复制到 U 盘 / 其他电脑，
  双击 `start.bat` 即可，不需要联网、不需要安装 Python
- `runtime/` 是官方 Python embeddable 发行版，删除它之后 start.bat
  会自动回退到系统已安装的 Python
- 存档都在 `saves/` 里，连同文件夹一起复制即可搬家

## 技术备注

- 模拟核心基于 WebAssembly，通过 `-v <rom路径>` 参数启动；
  页面会在启动前把一份核心配置写入 FS（`userdata/retroarch.cfg`），
  用于禁用与游戏冲突的内建热键（空格=按住快进、Esc=退出模拟器等），
  并把「重置」热键绑定到 F10
- 核心只接受合成键盘事件（虚拟手柄层的设计），页面中的转发器会把
  真实按键转换为合成事件喂给核心
- 存档文件名由核心按 ROM 名决定（game.nes → game.state），读档必须写到同名路径
- 核心把「读档」推迟到下一帧执行，暂停态下会自动先恢复一瞬再重新暂停
